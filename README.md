# 🐘 Shree Gajanan Puja Committee Website

Official website of **Shree Gajanan Puja Committee, Mirjapur & Paripundilo**.

A modern, mobile-first, high-performance static website designed to preserve and showcase our annual Ganesh Puja celebrations, committee activities, media archives, and financial transparency.

---

## ✨ Features

- 📱 Mobile-first responsive design
- 🌙 Dark mode (default) with Light mode toggle
- ⚡ Optimized for fast loading
- 🖼️ Lightweight hero image slider (2019–2025)
- 📅 Automatic upcoming event countdown
- 📢 Dynamic announcement banner
- 📂 Google Drive powered media archive
- 📄 Annual expense reports
- ♿ Accessibility-friendly
- 🔍 SEO optimized
- 📈 Progressive Web App (PWA)
- 📊 Lighthouse optimized

---

## 🛠 Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6)
- JSON Data
- Google Drive Integration
- GitHub Pages
